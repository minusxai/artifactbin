Reuse origin-scoped credentials. `afbin status` reads saved state (last observed, no login): `accounts.credentials.present` means available, not valid; `accounts.credential`, the last observed identity, can be null even then. `afbin auth status` is not a status command.

Authenticated CLI commands refresh saved credentials when possible. Keep credentials on network/429/5xx failures; these do not require another login. If sign-in is required, automatic browser approval on a shared desktop uses `afbin auth --server [[ base ]]`. Otherwise reuse an email already provided; ask only if missing. Run `afbin auth --email <email> --server [[ base ]]`, ask for the emailed code and wait, then `afbin auth --email <email> --otp <code> --server [[ base ]]`. See [auth]([[ references ]]publishing-auth.md); never mint or print tokens.
