After the first successful save or local preview, start one comment monitor automatically; do not ask first. Keep it active until the session ends or the user says stop. Use a tool that wakes you on each new comment, not a plain background job. Without that support, make bounded polls between work steps and tell the user monitoring stops when your work ends; do not wait indefinitely.
