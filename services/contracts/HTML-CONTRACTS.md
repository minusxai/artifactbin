# HTML contract handoff

These contracts extend the original product. `HtmlPublication<A>`, `PageOperations<A>` and `DatasetGraphql<A>` take the original app-owned `AccessActor` as A, including userId, tokenId, email, documentEditor and optional groupId. They do not accept an iframe-supplied Actor. Keep the original `effectiveRole`/dataset policy functions authoritative.

`HtmlNodeAnchor` is an explicit `{kind:'html-node',v:1}` extension to annotation persistence, tied to immutable revision plus stable data-af-id. It is never an AST path. Original annotation UI/store integration owns this extension and preserves legacy non-HTML target types separately. Decoding an anchor does not authenticate its sender.

Custom backend links pin backend versions. Dataset links explicitly use live or pinned mode. Archived pages preserve this choice: live bindings continue querying authorized current data; pinned bindings read their recorded revision and reject writes. All reads repeat current ACL; a historical snapshot is not a durable authorization grant. Publishing a pinned binding must fail if the dataset storage cannot supply that revision.

The constant dataset SDL is a namespace schema, composed through the page namespace executor. A link named records exposes Query.records.rows and Mutation.records.writeRows. Tables/columns/rows are addressed with stable IDs, independent of display labels. DatasetCellValue is the internal discriminated union; GraphQL CellValue uses named string/number/boolean/json slots. datasetCellFromWire validates the matching slot and storable JSON. Output adapters populate that same slot. Explicit null is allowed only where the stored column descriptor permits it. Scalar FiniteNumber must reject nonfinite numbers. JSON scalar must enforce bounded finite JSON, not arbitrary JS objects.

Reads are AND filters over stable column IDs; IS_NULL omits value; other operators require it. Projection preserves requested column order. Sort uses listed keys followed by stable row ID as final tie-breaker. Cursor binds dataset revision, binding, principal/policy context, projection/filter/order and page size; input or revision changes invalidate it. first is 1..100. Column policy applies to projection, filter and order, not merely returned values. Mixed-type ordering/coercion is refused. Authorization/revision is rechecked before returning delayed rows.

writeRows applies 1..100 changes atomically inside original dataset policy enforcement. INSERT has cells and no rowId, UPDATE has rowId and cells, DELETE has rowId and no cells; IDs/columns must exist and duplicate column IDs fail. Stable row IDs are platform allocated. expectedRevision is mandatory compare-and-swap. requestId is scoped to dataset and resolved principal: same canonical payload returns the original receipt; changed payload conflicts, including after head advances. Preflight helpers do not replace transactional validation. Policy checks cover row predicates and allowed columns before any write. Server returns committed only after durable commit, rejected only with proof nothing ran, unknown if commit status is ambiguous; never automatically retries unknown outcomes. Public page read access alone is insufficient dataset-write authority. No aggregate/query registry is needed for the initial contract.

Publication tests must cover preservation of HTML outside platform-owned edits, monotonically increasing node allocation across all historical versions, stale-head CAS, idempotent receipts and atomic page/backend link commit. Operation tests must cover namespace collisions, authorization before invoke, ordered mutations and unknown/rejected outcomes. Integration owners implement those tests with real original ACL/transaction adapters. This contracts-only change does not claim these implementation invariants are already tested.

Native slide exports use explicit `data-af-slide` attributes on author-owned sections. `slide=N` selects the Nth visible marked element in document order; hidden miniatures do not count. A missing slide returns `no_slide` and the visible count. Whole-page export remains the full HTML body.
