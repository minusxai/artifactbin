## Observed evidence

- New pure policy tests: 3/3 passed.
- New HTTP/Postgres boundary test: 1/1 passed against an isolated random schema, ephemeral loopback server and disposable example identities.
- Mutation proof: a temporary copy of `access.ts` with the scoped edit restriction removed failed the matrix at private/editor/scoped access (`edit: true` instead of `false`). The original source was untouched and temporary files were removed. The original matrix passed again in the combined run.
- Initial HTTP fixture runs exposed incorrect expected fixture status codes (publish/pair return 201; account-only sharing returns 401 for scoped tokens). Expectations were corrected to the existing contracts; these were test-authoring errors, not discovered product regressions.
- Broader suite rows above are code inventory, not fresh execution evidence. Full integrated verification remains the coordinating agent's responsibility.

## Integrated verification

- Coordinating run: typecheck/build and all 65 unit/server tests passed. Document, remote collaboration, publication and isolation browser stages passed.
- The library browser stage initially failed because its old exact-URL assertion excluded the new owner namespace. The assertion now requires the expected pathname and a nonempty namespace. Library checks then passed in Chromium, Firefox and WebKit; chrome/access, folder and durability stages passed.
- The owner-address browser regression now uses the actual browser URL for both another signed-in account and a guest; it no longer substitutes the sharing API's separately generated URL.
- CI runs the full `npm run check` sequence on the integrated commit before deployment.
